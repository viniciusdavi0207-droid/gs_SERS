🚀 Mission Control AI — Sistema Inteligente de Monitoramento Espacial

Projeto desenvolvido para a disciplina de Ciências da Computação com foco em lógica computacional, monitoramento automatizado e simulação de controle operacional de uma missão espacial experimental.

O sistema simula uma central de controle espacial capaz de:

Monitorar dados operacionais da missão
Detectar falhas automaticamente
Gerar alertas em tempo real
Executar respostas automatizadas com Inteligência Artificial
Analisar eficiência energética da nave
Exibir relatórios operacionais completos
🛰️ Sobre o Projeto

O Mission Control AI foi criado para simular o funcionamento básico de uma estação de monitoramento espacial.

Durante a execução, o sistema gera dados aleatórios relacionados a:

Temperatura da nave
Nível de energia
Potência operacional
Captação de energia solar
Status da comunicação

Com base nesses dados, o programa:

Analisa riscos operacionais
Identifica possíveis falhas
Ativa respostas automáticas
Atualiza o status dos módulos da nave
Exibe relatórios inteligentes
⚙️ Tecnologias Utilizadas
Python 3
Biblioteca random
Biblioteca time
🧠 Funcionalidades
✅ Geração de Dados Simulados

O sistema cria dados aleatórios para representar sensores da nave espacial.

✅ Sistema de Alertas

Detecta automaticamente situações críticas como:

Temperatura elevada
Baixa energia
Falha de comunicação
Baixa captação solar
✅ Inteligência Artificial Simulada

A IA toma decisões automáticas para corrigir problemas operacionais.

Exemplos:

Ativação do sistema de resfriamento
Economia de energia
Reinicialização da antena principal
Redirecionamento dos painéis solares
✅ Monitoramento dos Módulos

Atualiza o estado dos módulos da nave em tempo real.

✅ Relatórios Operacionais

Gera relatórios completos ao final de cada ciclo de monitoramento.

📋 Estrutura do Sistema

O código é dividido nas seguintes funções:
| Função                        | Descrição                     |
| ----------------------------- | ----------------------------- |
| `gerar_dados()`               | Simula dados dos sensores     |
| `verificar_alertas()`         | Detecta situações críticas    |
| `inteligencia_artificial()`   | Executa respostas automáticas |
| `analisar_sustentabilidade()` | Avalia eficiência energética  |
| `verificar_modulos()`         | Atualiza status dos módulos   |
| `exibir_painel()`             | Mostra painel da missão       |
| `gerar_relatorio()`           | Exibe relatório operacional   |
